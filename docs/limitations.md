# 实验限制与后续方向

1. **指标范围**：测量查询—段落二分类准确率，不是候选排序或 nDCG@10。官方 Rank1 使用标签位置概率归一化打分，本仓库的生成分类脚本没有实现该评分。
2. **验证集使用**：参与训练期间 loss 评估，也用于检查输出和修订停止规则；不能当作从未查看的独立测试集。先看过的 50 条包含在 500 条内。
3. **相关样本**：500 个样本对只有 495 个查询。分组 bootstrap 以归一化查询为单位，有放回抽取 495 个查询组，并计算样本对加权准确率；不是按 500 对完全独立抽样，也不是查询宏平均。
4. **区间含义**：百分位 bootstrap 是固定训练模型、固定验证集条件下的探索性抽样分析，不覆盖训练种子差异和验证集适应。单样本 Wilson 区间仅作为描述性附加量，主要表使用查询分组区间。
5. **统计结论**：不以 1.4 个百分点差异证明仅标签组普遍更好，不以跨过 0 的区间证明两组等价。旧报告中基于独立样本假设的 McNemar p 值不作为主要证据。
6. **训练控制**：两组相同输入、主要超参数和可训练模块；输出 token 数不同，训练计算预算并不相同。仅一个随机种子，输出不追加 EOS，生成使用任务停止规则。
7. **参数范围**：除 LoRA 外完整训练嵌入与输出头，约 5.04 亿可训练参数。不能表述为仅训练少量 LoRA 参数；不证明当前设置是必要或最省资源的方案。
8. **硬件与耗时**：推理组与标签组在不同实例 GPU 上评估，历史耗时可查但不能用于严格加速比。生成 token 数可比较，但同时受任务监督与终止规则影响。
9. **原论文差异**：本文 1.5B/5000 样本/一轮/分类验证；原论文的重要推理链消融为 7B/BRIGHT 排序。不能声称复现其 17.5→27.5 nDCG@10。
10. **解释性**：错误输出中可见自相矛盾和不必要假设，不代表已经识别内部因果机制，也不等于推理链忠实性研究。
11. **权重**：未发布微调权重，需要重新训练才能恢复模型推理。已保存预测允许审核分数，但不能替代模型权重。

可选后续：多个训练种子；独立来源测试；BRIGHT 固定候选重排；同卡测速；对推理内容进行干预以检验其作用。以上均未完成。
